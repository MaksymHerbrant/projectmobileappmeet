# Дизайн Meet

Полотно з 21 екраном у гамі Графіт. Кольори взяті з `lib/theme/app_theme.dart`,
а не підібрані окремо — макет і застосунок мусять збігатися.

- `*.dc.html` — по одному екрану, вихідні файли полотна
- `canvas.json` — розкладка: чотири ряди за порядком шляху користувача
- `meet-design.html` — зібране полотно (публікується як артефакт)

Кожен екран має перемикач теми над рамкою: світла / темна.

Перезбирання після правок у `.dc.html` описане в історії задачі — правки
зручніше робити прямо на полотні й зберігати там.
